Лабораторная работа 1
Копирование файла с использованием перекрывающегося ввода-вывода (POSIX AIO)

Цель работы:
Реализовать консольное приложение для копирования файла с использованием перекрывающихся операций ввода-вывода и провести экспериментальное исследование влияния размера блока данных и числа перекрывающихся операций на производительность копирования.

Описание реализации:
В работе реализовано копирование файла с использованием механизма асинхронного ввода-вывода POSIX AIO.

В Linux-реализации использованы следующие функции:
– open() — открытие и создание файлов;
– fstat() — получение размера файла;
– aio_read() и aio_write() — асинхронные операции чтения и записи;
– aio_suspend() — ожидание завершения операций;
– aio_return() — получение результата завершённой операции;
– clock_gettime(CLOCK_MONOTONIC) — измерение времени выполнения.

Сборка программы:

gcc -O2 -Wall -Wextra -std=c11 mainLinux.c -o aio_copy -pthread

После сборки создаётся исполняемый файл aio_copy.

Создание тестового файла
Пример создания файла размером 1 GiB:

dd if=/dev/zero of=big.bin bs=1M count=1024 status=progress
sync

При необходимости можно изменить размер файла, изменив параметр count. В нашем случае, необходимо проверить еще 256 MiB и 512 MiB

Эксперимент 1
Зависимость скорости копирования от размера блока данных.

Фиксированное значение:
n_ops = 2

Запуск:

chmod +x blocksize.sh
./blocksize.sh

Эксперимент 2
Зависимость скорости копирования от числа перекрывающихся операций.

Фиксированное значение:
block_size = 1048576 (1 МиБ)

Запуск:

chmod +x nops.sh
./nops.sh

Проверка корректности копирования:
Для сравнения исходного и результирующего файлов используется команда:

cmp -s big.bin copy.bin && echo OK || echo DIFF

Параметры экспериментов:
Размер тестового файла: 1 GiB
Размер блока файловой системы: 4096 байт
Исследуемые значения block_size: от 4 KiB до 4 MiB
Исследуемые значения n_ops: 1, 2, 4, 8, 12, 16

Результат:
По итогам экспериментов определяются оптимальный размер блока данных, оптимальное число перекрывающихся операций и характер зависимости скорости копирования от исследуемых параметров.

Примечание:
Следует учитывать, что результаты измерений могут зависеть от механизма кэширования файловой системы (page cache) операционной системы. При повторном запуске программы часть данных может обслуживаться из памяти, что приводит к увеличению измеренной скорости копирования по сравнению с физической пропускной способностью накопителя. Однако это не влияет на характер зависимостей и выбор оптимальных параметров.
