* определения

    вычислительная система - это совокупность аппаратных средств вычислительной техники и программного обеспечения, предназначенная для обработки информации

    структура вычислительной системы:
        аппаратное обеспечение (контроллеры, шины, монитор и т.д.) -> микроархитектура (регистры цп, алу) -> машинный язык -> операционная система -> утилиты, компиляторы, редакторы,          интерпретаторы команд -> прикладные програамы
        
    вычислительная система может не иметь операционной системы - например, изначально они были аналоговыми, а "программы" задавались щелчком тумблеров

    операционная система - это комплекс системных программ, обеспечивающий оптимальное управление ресурсами вычислительной системы в соответствии с некоторым критерием эффективности

    критерием эффективности ос может быть, например, пропускная способность (число выполненных задач за единицу времени) или реактивность (время реакции на некоторое событие) системы. данные критерии обратны друг другу, т.к. на переключение задач необходимо время/ресурсы

    основной функцией ос является управление аппаратными ресурсами вычислительной системы

* задачи управления ресурсами

    ресурсы бывают делимые/неделимые, а делимые ресурсы могут делиться одновременно или попеременно
        процессорное время - делится попеременно
        оперативная память - делится одновременно и попеременно
        файлы - делятся одновременно
        внешние устройства ввода/вывода (принтеры, сетевые устройства и т.д.) - делимые и неделимые

    управление аппаратными ресурсами вс требует решения следующих задач, не зависящих от типа ресурса:
        - планирование и удовлетворение запросов на ресурсы - кому, когда (и сколько) выделять ресурсов
        - отслеживание состояния ресурса - поддержание оперативной информации о том, занят ли ресурс и какое количество свободно/распределено (для делимых ресурсов) 
        - разрешение конфликтов за доступ к ресурсам

* мультипрограммирование

    мультипрограммирование - метод "одновременного" выполнения на одной ВС нескольких программ или различных ветвей одной и той же программы. в настоящее время в большинстве операционных систем определены два типа единиц работы (job), иногда называемых задачами, между которыми разделяется процессор и другие ресурсы компьютеры: процесс и поток

    процесс - абстракция, описывающая выполняющуюся программу. для ос процесс представляет собой единицу работы, заявку на потребление системных ресурсов. одним из основных ресурсов является адресное пространство процесса, т.е. оперативная память, выделенная процессу
    поток - последовательность выполнения инструкций процессора. процесс в этом случае рассматривается как заявка на потребление всех видов ресурсов, кроме одного - процессорного времени, которое ОС распределяет между потоками. таким образом, поток представляет собой мини-процесс, который работает в адресном пространстве породившего его процесса
    в простейшем случае процесс состоит из одного потока, именно таким образом трактовалось понятие "процесс" до середины 80-х годов
    
    в л/р в соответствие одному потоку будет ставиться одна функция
    
    web-сервер - это пример многопоточного приложения
    
* основные состояния процессов и потоков
  -> выполнение -> ожидание -> готовность ->
  готов к выполнению - ждет цп
  выполняется - цп предоставлен
  приостановлен - ждет некоторого события (например, ввод/вывод)
  
  планирование потока на ядро может происходить разными способами (в зависимости от операционной системы)

* признаки классификации ос
  - относительно их управлением процессами
      - однозадачные (ms-dos, msx)
      - многозадачные (windows, unix)
        - невытесняющая многозадачность (активная задача выполняется до тех пор, пока она не отдаст управление обратно ос для выполнения другой задачи)
        - вытесняющая многозадачность (решение о переключении процессора между задачами принимается ос)
          - абсолютный приоритет (наиболее прироритетная задача СРАЗУ забирает процессор)
          - относительный приоритет (выполняемая задача довыполняется, после чего наиболее приоритетная задача начинает выполнение)
  - относительно числа "одновременно" работающих пользователей ос
    - однопользовательские
    - многопользовательские (не обязательно одновременная работа нескольких пользователей! достаточно нескольких сессий)
  - относительно поддержки многопроцессорной обработки
    - асимметричные ос (код ядра выполняется только на одном процессоре, остальные распределяются по приложениям)
    - симметричные ос (код ядра может выполняться одновременно на всех процессорах)

адаптивное планирование: если какой-то поток не получает необходимый ему ресурс в течение некоторого времени, его приоритет повышается

* типы многозадачных ос
 - системы пакетной обработки
 - системы разделения времени
 - системы реального времени
 
 системы пакетной обработки:
     оператор ос должен обеспечивать сбалансированную загрузку всех устройств ВС
     основной задачей операционных систем пакетной обработки тогда была обработка исключений
 системы разделения времени:
     в отличие от спо, предоставляют интерактивность системы
 системы реального времени:
     - hard real-time: при нарушении временных ограничений может возникнуть критическая ошибка
       - используются для управления тех. объектами (станками и т.п.), где при нарушении предельно допустимого времени может произойти авария
     - soft real-time: нарушение временных ограничений не приводит к отказу
 
 гибридные системы:
     - современные ос могут совмещать в себе свойства систем разных типов (часть задач выполняется пакетной обработкой, часть - в реальном времени)
     
 * основные способы структурной организации
   - монолитная структура
     - система компонуется как одна программа. для этого необходимо скомпилировать все отдельные структуры, а затем связать их в один файл
   - многоуровневая структура
     - система имеет разные группы функций (файловая система, системные сервисы и т.д.). каждая группа может использовать группы только степенью НИЖЕ
   - 
   
 ядро - центральная часть ос, выполняющая основные функции. основная функция ядра ос - управление процессором
 
 в идеале ядро должно быть защищенным, чтобы пользовательский код не мог помешать работе ядра. это называется привилегированным режимом
 в некоторых случаях разработчики ос организуют работу ядра и приложений в одном режиме (например, в привилегированном)
 
 наиболее классическим вариантом является монолитное ядро. оно должно целиком находиться в оперативной памяти
 альтернативным вариантом является модульное ядро. оно не требует изменения всего кода для изменения функционала части ядра
 также существует микроядро, которое выполняет только минимум функций для управления аппаратурой, в то время как другие функции ос выполняются самими компонентами ос
